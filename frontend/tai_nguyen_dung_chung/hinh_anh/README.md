# Thư mục lưu trữ hình ảnh & logo dùng chung của giao diện (Frontend Assets)

Bạn hãy sao chép hoặc lưu file logo của bạn vào thư mục này:

- **Đường dẫn thư mục đầy đủ:** `c:\xampp\htdocs\DOAN\frontend\tai_nguyen_dung_chung\hinh_anh\`
- **Tên file logo chuẩn:** `logo.png` (hoặc `logo.svg`, `logo.webp`, `logo.jpg`)
- **Đường dẫn web tự động:** `/tai_nguyen_dung_chung/hinh_anh/logo.png`

Khi bạn bỏ file `logo.png` vào thư mục này, hệ thống trên trang web sẽ tự động nhận diện và hiển thị logo của bạn tại:
1. Logo chính điện khổng lồ trên trang Chào Mừng (Landing Page).
2. Logo trên thanh Menu điều hướng (Header Navigation).
3. Logo trên thanh bên và trang Đăng nhập / Đăng ký.
